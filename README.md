# Card Game Systems

A web-based card game system built with HTML, CSS, and JavaScript. This project includes prototypes for game animations, logic separation, and core game mechanics.

## Features

- **Card Mechanics**: Drawing, summoning, and battling cards
- **Game Phases**: Turn-based gameplay with distinct phases
- **UI Rendering**: Board, field, and hand visualization
- **Animations**: Smooth transitions for card actions
- **State Management**: Centralized game state and reducer logic

## Project Structure

- `index.html`: Main entry point
- `animation_prototypes/`: HTML files demonstrating card animations (defeat, draw, summon, etc.)
- `logic_prototypes/`: HTML files for game logic experiments
- `scripts/`: JavaScript modules
  - `Game.js`: Main game class
  - `Main.js`: Entry point
  - `actions/`: Action handlers (draw card, use card, events)
  - `engine/`: Core game engine (state, phases)
  - `UI/`: Rendering components (board, field, hand)
- `styles/`: CSS files for styling and animations
- `TODO.txt`: Development notes

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)

## Setup and Usage

1. Clone or download the project.
2. Open `index.html` in a modern web browser.
3. Interact with the game interface.

No additional dependencies or build steps required.
